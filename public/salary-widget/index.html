Frequently asked questions




Is the widget really free?


Yes — free for job boards, recruiters, staffing agencies and careers pages. No signup, no API key, no usage limit. We only ask that you keep the small credit link under the widget.


How accurate are the figures?


The widget runs the same tax logic as Tabutility's live 2026 salary calculators: current-year brackets, social contributions and standard credits for a typical single employee. Assumptions are stated inside the widget. Figures are estimates for guidance, not tax advice.


Can I preset the salary from my listing?


Yes — pass it in the URL: /widget/?c=uk&s=50000. On a templated job board, inject each listing's salary into the iframe URL and every posting gets its own personalised widget. Candidates can also edit the number inside the widget.


Will it slow my pages down?


No. It's one static HTML file under 15 KB, no external libraries, no cookies, served from a global CDN. With loading="lazy" it has zero impact on your page speed scores.


Can you add a country or a custom style?


Probably! The widget is built from Tabutility's country calculators — if we cover the country, we can widget it. Get in touch via tabutility.com.
